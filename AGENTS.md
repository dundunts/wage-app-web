## Agent skills

### Releases

For a release, hotfix, deployment, promotion, rollback, or a change to the
application runtime contract, use
`.agents/skills/release-wage-app-service/SKILL.md`.

### Issue tracker

Issues and specs are tracked in GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels

Triage uses the default canonical label vocabulary. See `docs/agents/triage-labels.md`.

### Domain docs

Domain documentation uses a single-context layout. See `docs/agents/domain.md`.
